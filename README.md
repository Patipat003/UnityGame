# Crime Investigation (Unity Project)

🎓 **Final Year Project (University)**

## Description

**Crime Investigation** is a 3D crime investigation game developed using Unity. The game features various systems that simulate real investigative scenarios in an interactive environment.

### Core Features:

- **Basic Player Controls**: Movement and interaction with the environment.
- **Score Tracking**: Track your performance throughout the level.
- **Point Collection**: Earn or lose points by taking correct or incorrect actions.
- **In-Level Interactions**: Interact with objects and environments relevant to each case.
- **Photo Camera System**: Take photos of evidence to build your case.
- **Tablet with UI Interface**:
  - **Crime Details**: Information on each case and witness testimonies.
  - **Wiki**: Search and learn more about items and evidence found.
  - **Gallery**: View all photos you’ve taken.
  - **Exam**: Answer case-related questions to conclude each level and earn points.

The project was developed using **Unity version 2022.3.20f1**.

> ⚠️ This repository only contains the **source code** used in the development of the game. Due to size constraints, the full Unity project is not included.
